# LXPlayground Prompts

Welcome to the **LXPlayground Prompts** repository. This project serves as a centralized hub to keep, manage, and version various AI model prompts used across different repositories and projects.

## Context & Purpose

As AI models become more integrated into diverse codebases and frameworks, maintaining consistency and tracking changes in instructions is crucial. This repository is designed to provide:

*   **Single Source of Truth:** All external repositories and AI models fetch their base instructions from this central location.
*   **Version Control Integration:** By assigning semantic versions to individual prompts, external repositories can lock into a specific prompt version, ensuring that updates here do not cause breaking changes elsewhere.
*   **Modularity & Organization:** Prompts are categorized by domain (e.g., `car`, `account`), further divided by system types (e.g., `user`, `org`), and finally by specific technologies, making them highly cohesive and easy to navigate.
